# DISCOVER — CURADORIA PARA ARKANA

## Objetivo
Usar Discover como estoque de base para cenário e props, reduzindo créditos e tempo.

## Prioridade
1. CC0.
2. Sem referência explícita a personagem/franquia de terceiros.
3. Silhueta compatível.
4. Estilo stylized.
5. Geometria separável.
6. Materiais fáceis de substituir.
7. Escala plausível.

## Classificação interna

### USAR
Compatível quase direto; aplicar material/shader Arkana.

### ADAPTAR
Boa geometria, estilo/textura precisam alteração.

### REFERÊNCIA
Não usar mesh; aproveitar ideia estrutural.

### DESCARTAR
Incompatível, muito realista, muito complexo, IP alheio, licença incerta ou desempenho ruim.

## Registro
Cada asset aprovado recebe:
- URL;
- criador;
- licença na data do download;
- screenshot da página/licença;
- arquivo original;
- versão modificada;
- lista de alterações.

## Proibição
Mesmo quando um modelo está marcado CC0, descartar asset que seja claramente cópia/derivado de IP reconhecível.
