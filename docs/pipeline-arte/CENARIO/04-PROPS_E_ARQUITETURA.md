# PROPS E ARQUITETURA

## O que procurar primeiro no Discover
- árvores;
- pedras;
- cliffs;
- arcos;
- paredes;
- colunas;
- portais;
- cristais;
- altares;
- estátuas genéricas;
- caixas;
- barris;
- bancos;
- tochas;
- placas;
- pontes;
- entulho.

## O que preferir gerar autoral
- artefatos de Sintonia;
- torres com função de gameplay;
- símbolos centrais;
- props de lore;
- itens associados diretamente a personagens;
- landmarks principais.

## Regra anti-asset-flip
Todo asset externo deve receber pelo menos uma das ações:
- retextura;
- shader Arkana;
- mudança de escala/proporção;
- kitbashing;
- decal/runa;
- cor/roughness;
- modificação geométrica.

Landmarks recebem alterações maiores.

## Critério
Um jogador não deve perceber quais objetos vieram da comunidade e quais foram gerados do zero.
