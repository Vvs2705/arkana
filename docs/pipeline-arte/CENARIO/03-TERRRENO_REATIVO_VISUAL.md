# TERRENO REATIVO — DIREÇÃO VISUAL

## Fogo
Estados visuais:
1. seco/normal;
2. aquecendo;
3. queimando;
4. brasas;
5. carvão.

Precisa ser legível sem HUD.

## Água/Gelo
Gelo:
- superfície mais clara;
- bordas;
- trincas;
- leve emissão/refração estilizada;
- não usar transparência cara em excesso.

## Eletricidade na água
- pulsos;
- linhas superficiais;
- flashes curtos;
- evitar partículas cobrindo a tela.

## Lama
- cor mais escura;
- brilho/roughness diferente;
- afundamento visual leve;
- footprints opcionais.

## Terra
Muro criado:
- silhueta imediata;
- rachaduras de dano;
- estado próximo de quebrar.

## Vento
O vento deve ser visto por:
- folhas;
- poeira;
- fitas/linhas;
- distorção muito controlada.

## Técnica
O sistema lógico do terreno deve permanecer separado da apresentação.
Assets são estados visuais; não são a regra de gameplay.
